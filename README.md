# renovliesnoord.nl

Dit is de website van **renovliesnoord.nl**: wandafwerking met Ekotex Sprint renovlies en sausen met Ekotex 8100 (optie 8300), in Leeuwarden en omgeving.

Het is een eenvoudige statische HTML-site:

- `index.html` – startpagina
- `offerte.html` – offerte aanvragen
- `contact.html` – contactgegevens
- `css/`, `js/`, `assets/` – opmaak, scripts en afbeeldingen

## Online zetten

De site staat op GitHub en wordt automatisch gepubliceerd door Netlify. Elke wijziging die naar de `main`-branch wordt gepusht, staat binnen een minuut live. Er is geen build-stap nodig; Netlify publiceert de map zoals hij is.
